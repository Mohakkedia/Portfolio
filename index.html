FileFlow Agent

Jun 2026

Project Overview

A privacy-first autonomous agent that converts repetitive file-system activity into intelligent, safe automation. Combines FAISS semantic memory, Llama3 local reasoning, and a sandboxed human-in-the-loop runner to execute local file workflows without exposing data to external APIs.

Key Methodologies

  • FAISS Memory: Stores and retrieves workflow patterns using vector similarity search for context-aware automation decisions.
  • Llama3 Reasoning: Local LLM processes natural language instructions and orchestrates multi-step file operations entirely on-device.
  • Human-in-the-Loop: Sandboxed runner requires human confirmation for destructive or ambiguous file operations, ensuring safety.
  • Privacy-First: Zero external API calls — all inference and memory run locally.

Fintech Transaction Fraud & Risk Audit Pipeline

Jun 2026

Project Overview

An end-to-end data engineering and analytics pipeline that audits credit card transactions, computes risk metrics, and triggers automated predictive modelling runs. Built on a modern DataOps Medallion Architecture (Raw → Staging → Marts) using industry-standard tools.

Architecture & Methodology

  • Medallion Architecture: Structured data flow from Raw ingestion zone through Staging transformations to production-ready Marts in Snowflake.
  • Workflow Orchestration: Apache Airflow DAGs orchestrate ingestion (Snowflake COPY INTO), dbt compilation, testing, and model training triggers.
  • dbt Transformations: Custom SQL macros, staging models, and mart tables with built-in data quality tests transform raw transaction data into analytics-ready risk metrics.
  • MLOps Integration: Dataiku DSS API-driven model retraining pipeline enables automated fraud classifier updates on new data.
  • Mock Data Generator: Python-based synthetic transaction generator for development and testing.
